# First JavaScript Page

Practice assignment based on slide 6 of my class slides.

## What it does
Clicking "Book Appointment" changes the heading to
"Thank you for booking!" and makes it purple.
This is a practice page; it does not book an appointment.

## Files
- index.html: page structure
- style.css: page styling
- app.js: click behavior

## How to run
Open index.html in a browser and click the button.
