# First JavaScript Page

Practice assignment based on slide 6 of my class slides.

## What it does
Clicking "Book Appointment" changes the heading to
"Thank you for booking!" and makes it purple.
This is a practice page; it does not book an appointment.

## Files
- index.html: page structure
- style.css: page styling
- app.js: click behavior

## How to run
Open index.html in a browser and click the button.

## What I learned
- Connecting HTML, CSS, and JavaScript
- Using defer
- Handling a click event
- Changing text and adding a CSS class
- Checking filenames, spaces, and missing instructions

- Using console.log() to check when code runs
- Code outside the click callback runs when the file loads
- Code inside the click callback runs on each click

- Practicing JavaScript syntax and typing accurately
- Using quotes, parentheses, semicolons, and curly braces
- Writing comments with //
- Using the correct capitalization in console.log()

- Declaring variables with const
- Using variable values in calculations
- Calculating a result does not change the stored value
- const prevents reassignment
